## 📖 Overview

Choosing the right college is one of the most important decisions for students. The **College Discovery Platform** simplifies this process by providing detailed college information, intelligent comparison tools, admission prediction features, and a collaborative student discussion forum.

Whether you're searching for the best engineering college, comparing fees and placements, or estimating admission chances, this platform offers everything in one place.

---

## ✨ Features

### 🔍 Smart College Search
- Search colleges by name
- Filter by location
- Filter by fee range
- Browse top institutions easily

### ⚖️ College Comparison
- Compare multiple colleges side-by-side
- Analyze:
  - Fees
  - Ratings
  - Placements
  - Location
  - Facilities

### 🎯 Admission Predictor
- Estimate admission chances
- Input academic scores
- Get personalized predictions

### 💬 Student Discussion Forum
- Ask questions
- Share experiences
- Interact with other students

### 🏫 Detailed College Profiles
- College overview
- Ratings & reviews
- Placement statistics
- Fee structure
- Location details

### 🔐 Authentication System
- User Registration

- Secure user sessions

### 📱 Responsive Design
- Mobile Friendly
- Tablet Compatible

## 🚀 Installation

### Clone Repository

```bash
git clone https:/Yukta062006/github.com//College-Discovery-Platform.git
```

```bash
cd College-Discovery-Platform
```

---

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at:

```text
http://localhost:5173
```

---

### Backend Setup

Open a new terminal:

```bash
cd backend
npm install
npm run dev
```

Backend runs at:

```text
http://localhost:5000
```
